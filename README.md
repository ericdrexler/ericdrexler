# K. Eric Drexler

Researcher and author working on AI strategy and governance, AI system
architecture, and prospects for advanced nanotechnologies.

- **Current writing:** [AI Prospects](https://aiprospects.substack.com) (Substack) and a model-oriented [research library](https://ericdrexler.github.io/research-library/) (GitHub)
- **Books:** *Engines of Creation* (1986), *Nanosystems: Molecular Machinery,
  Manufacturing, and Computation* (1992), *Radical Abundance* (2013)
- **Selected report:** *Reframing Superintelligence: Comprehensive AI Services
  as General Intelligence* (FHI Technical Report, 2019)
